# Farm
## Назначение
Основной микросервис проекта Farm

Взаимодействует с микросервисами через gRPC
- [Announcements](https://github.com/customerchik/Farm-Announcements) — управление объявлениями
- [Images](https://github.com/customerchik/Farm-Images) — сохранение и выдача изображений пользователям сайта
- [Messenger](https://github.com/customerchik/Farm-Messenger) — внутренний мессенджер
- [Users](https://github.com/customerchik/Farm-Users) — управление пользователями

## Функционал
- Принимает внешние запросы от пользователей, а после обработки возвращает им html странички или информацию в формате json
- Для обработки запросов пользователей взаимодействует с соответствующими микросервисами по архитектуре оркестрации
- В случае попытки запроса по несуществующему пути возвращает страницу html с ошибкой 404
- Микросервис отвечает за создание сессий для пользователей. В случае если сессии сохраненой на клиенте пользователя не существует перенаправляет на авторизацию

## Переменные окужения
Для корректной работы необходимы переменные окружения: <br>
DB_HOST - адрес БД<br>
DB_PORT - порт БД<br>
DB_USER - пользователей БД<br>
DB_PASSWORD - пароль пользователя БД<br>
DB_NAME - название БД<br>
ANNOUNCEMENTS_SERVICE_HOST_GRPC_PORT - адрес и порт микросервиса Announcements для взаимодействия по gRPC<br>
IMAGES_SERVICE_EXTERNAL_CONNECTIONS - адрес и порт микросервиса Images для внешний подключений (получение картинок)<br>
IMAGES_SERVICE_HOST_GRPC_PORT - адрес и порт микросервиса Images для взаимодействия по gRPC<br>
MESSENGER_SERVICE_HOST_GRPC_PORT - адрес и порт микросервиса Messenger для взаимодействия по gRPC<br>
USERS_SERVICE_HOST_GRPC_PORT - адрес и порт микросервиса Users для взаимодействия по gRPC<br>

## Сборка и запуск
Установите Docker в случае если он не имеется<br>
Используйте скрипт развертывания проекта из документации (install.sh для Linux или install.ps1 для Windows). Данный скрипт скопирует репозитории всех сервисов, создаст базы данных в Dcoker и запустит сервисы<vr>
В дальнейшем для запуска проекта используйте команду в директории, где находится файл docker-compose.yml (там где изначально запускали скрипт развертывания):
```
docker compose -d --build
```
